# Fase Tensiva — Tracking App

App de tracking de treino para a Fase Tensiva (A/B split, 6 semanas).

## Funcionalidades

- **Treino A / B** — registo de séries, pesos e reps por sessão
- **A Short / B Short** — versão comprimida com cardio
- **Calendário** — sequência semanal dinâmica A·B·As·B·A·Bs
- **Referência** — tabela de exercícios, séries, reps e descanso
- **Auto-save** — localStorage, persiste entre sessões
- **Export/Import** — backup em JSON

## Como usar

Abre `index.html` no browser ou acede via GitHub Pages.

Para instalar como PWA no iOS: Safari → Partilhar → Adicionar ao ecrã inicial.

## Estrutura

```
index.html     — app completo (ficheiro único)
manifest.json  — PWA manifest
README.md      — este ficheiro
```
